## Config and run

```yaml title="uzh_fpv_snapdragon_indoor_45_cam_imu.yaml" {1-6,12-18,20,24-25}
gravity: 9.8070   # m/s², Innovation Park Zürich, Dübendorf, Switzerland
site:
  latitude_deg: 47.4
  longitude_deg: 8.62
  altitude_m: 440
  name: Innovation Park Zürich, Dübendorf, Switzerland
input:
  format: ros1
  path: indoor_45_calib_snapdragon_imu.bag
  imu_topics:
  - /snappy_imu
board:
  board_type: apriltag
  rows: 4
  cols: 5
  tag_size: 0.075
  tag_spacing: 0.2
  tag_family: t36h11
camera_input:
  path: camchain-..indoor_45_calib_snapdragon_cam.yaml
  estimate_readout: false
solve:
  imu_intrinsics: dw_da
  estimate_t_ga: true
  sigma_g: 0.0007110208680826167
  sigma_a: 0.0032732613574351305
  sigma_bg: 7.110208680826167e-05
  sigma_ba: 0.00032732613574351307
output:
  path: cam_imu.json
```

```bash title="shell"
mvis cam-imu -c uzh_fpv_snapdragon_indoor_45_cam_imu.yaml
```
